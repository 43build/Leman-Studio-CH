La commune ne désigne plus votre ramoneur

Depuis le 1er juillet 2025, le choix vous revient. Le ramonage, lui, reste obligatoire.

Ce qui change

  • Vous choisissez un maître ramoneur autorisé.
  • Prix libres, que le canton veut affichés.
  • Tarifs : à compléter

Ce qui reste

  • Les fréquences du tableau ci-dessus.
  • Deux passages : au moins un en saison de chauffe.
  • Usage occasionnel : un contrôle annuel quand même.

Le conduit siffle : feu de cheminée

  1. Appelez le 118. Prévenez toute la maison.
  2. Pas d’eau : la vapeur peut faire éclater le conduit.
  3. Éloignez ce qui touche le conduit, grenier compris.
  4. À la demande des pompiers, le ramoneur de piquet vient dans l’heure.
